# AI Science Research

> 粤港澳大湾区 AI Coding 创新应用大赛 · **赛题方向二：AI + 学术科研助手**

**科研小助理** —— 面向大一新生的科研启蒙与成长助手。通过科研认知测评、个人画像、个性化学习路线，以及带出处的实验室与导师公开资料，帮助学生从"不了解科研"走到"采取第一个科研行动"。

## 项目状态

🚧 **早期开发中。** 选题已确定为「科研小助理」，Web 应用骨架尚未搭建，因此本仓库目前只有项目文档与开发经验记录。

📌 **动手之前先读 [总控文档](docs/总控文档.md)** —— 它规定开发步骤、基准文档，以及每个人使用自己的 AI agent 时应遵守的规则。

## 技术栈

| 用途 | 选型 |
|---|---|
| 全栈框架 | Next.js（App Router）+ TypeScript，Node.js `22.x`，pnpm |
| 界面 | Tailwind CSS + shadcn/ui，React Hook Form + Zod |
| 数据库 | CloudBase PostgreSQL 17（经 PostgREST，**不需要连接池**） |
| 数据访问 | **Repository 适配器** —— 所有数据库访问必须经它 |
| 身份认证 | 服务端**匿名会话方案 A**（HttpOnly Cookie + Token 哈希落库） |
| AI | `AI_PROVIDER=disabled` 默认，仅保留可替换的 Provider 接口 |
| 部署 | Vercel，函数区域 `hkg1`（中国香港） |

技术选型不是"哪个火用哪个"，每一条都对应赛事平台或云环境的真实约束。例如：函数区域必须手动改成 `hkg1`，因为默认是美东，而评委在深圳；数据库走 PostgREST，是因为该 CloudBase 实例**不提供 `pg` 直连**（已实测确认）。

> 完整架构与理由见 [总控文档](docs/总控文档.md) §三，以及[《AI实施任务书》](docs/傅加贝/AI实施任务书.md) §1。
