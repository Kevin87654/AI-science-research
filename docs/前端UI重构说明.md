# 前端 UI 重构说明（v3 视觉系统 · 黑白工业风）

> 类型：**随开发演进**的文档（可直接改，不必等评审）。改的是外观与导航形态，**没有动任何业务逻辑与接口**。
> 起因：比赛演示需要一个更"新潮"的第一印象 —— 大图打底 + 贴边自动呼出的功能菜单。
> v3 调整（评审第一轮反馈）：**边角一律改直角**、整体转向**黑白工业风**、**黄色占比大幅减少且调浅**。

## 1. 黑白工业风的三条规矩

1. **一律直角**（`--radius: 0`）。按钮、卡片、输入框、标签、状态胶囊、品牌方块全部是方块，
   不再用圆角与胶囊形。
2. **主色是白，不是黄**。按钮/选中态/进度条用**白底黑字**（工业风的白块），
   黄只在三处出现：**当前项左侧竖条 / hover 态 / 「演示数据」角标**，以及少量文案强调色。
3. **去掉辉光与柔光**。卡片不再有外发光、黄光晕；层次靠 1px 描边 + 极浅的白色叠底（`rgba(255,255,255,.03~.08)`）。

色板集中在 `src/app/globals.css` 的 `:root`，改色只改那里：

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--bg` / `--bg-deep` | `#06070a` / `#000205` | 全站底色 |
| `--ink` | `#f4f5f2` | 正文白 |
| `--accent` | `#ffeb9a` | **浅黄**，仅作点缀（不是主色） |
| `--accent-ink` | `#0a0b0d` | 落在白底/黄底上的字色 |
| `--line` / `--line-soft` / `--line-strong` | `rgba(255,255,255,.14/.08/.32)` | 描边三档 |
| `--muted` / `--faint` | `#9aa0a6` / `#6b7076` | 次级与三级文字 |

按钮语义：`.button`（主）= 白底黑字，hover 变浅黄；`.button-secondary` = 透明 + 1px 白描边；
`.button-ghost` / `.button-small` 同理。**黄只在 hover 时出现**，所以页面静止时几乎看不到黄。

状态色也走黑白体系：`status-completed` = 白底黑字实块；`status-in-progress` = 浅黄描边 + 浅黄字；
`status-not-started` / `skipped` = 灰。只有错误提示（`.error-text`）保留一点去饱和的红，保证能一眼认出。

## 2. 背景大图

- 素材：`public/brand/key-visual.jpg`（首页主视觉：夜空下的光树）、
  `public/brand/backdrop.jpg`（内页底纹：轨道线）。均为 2560×1440。
- 由 AI 文生图生成（pollinations.ai 免费接口，输出 1024×576），本地用 LANCZOS 放大到 2560×1440、
  抹掉服务方水印、补少量噪点，并**大幅降饱和（color 0.30～0.35）压成黑白**，只留一丝暖调。
  **属于 AI 生成素材，对比赛材料无版权争议**；换成实拍或设计稿直接覆盖同名文件即可，代码不用动。
- 承载层 `.backdrop`（`position: fixed` + `pointer-events: none`），四层叠加：
  `-photo`（图）/ `-glow`（很淡的冷暖双向光）/ `-grid`（72px 网格，径向遮罩）/ `-veil`（左右 + 上下压暗）。
- 首页与内页用不同档位：首页 90% 且偏右；内页压到 42%、更靠右，保证正文区域足够暗。
- ⚠️ 主体位置用 `transform: translateX() scale()` 调，**不要用 `background-size` 百分比** ——
  竖屏下会露出底色。图片本身是放大来的，过大的 `scale` 会发虚。

## 3. 左侧自动呼出菜单（dock）

`src/components/app-shell.tsx`（客户端组件，挂在 `layout.tsx`，全站唯一）。
收起时只占左侧 16px（触屏 26px）窄栏；鼠标移入 / 键盘聚焦 / 点「固定」→ 滑出 248px 面板。

- 导航项集中在 `src/components/nav-items.tsx`，**顶栏与侧栏共用同一份**，不要再各写一遍。
- **当前项 = 近白实块 + 黑字 + 3px 浅黄左竖条**（对齐参考站那套「浅色实块 + 左竖条」的形态）。
- 面板里的链接**始终在 DOM 中**（靠 `transform` 移出视野，而不是 `display: none`），
  这样键盘 Tab 进来时 `:focus-within` 能把面板拉开，导航可达。
- 遮罩 `.dock-scrim` 默认 `pointer-events: none`：如果让它接事件，鼠标划过页面会一直停在
  `.dock:hover` 上，菜单关不掉。只有「已固定」状态才允许点击遮罩收起（触屏用）。
- 触屏没有 hover，**窄栏上的按钮是唯一入口**；`@media (hover: none)` 会把窄栏加宽到 26px。

## 4. 顶栏

`src/components/site-header.tsx`：品牌 + `匿名体验` 说明 + `编号 / 英文名` 面包屑 + 主行动按钮（白底方块）。
导航本体已经移到侧栏，顶栏刻意做薄，让背景大图成为视觉主体。
测评页会隐藏顶栏的「开始测评」（页面自己有同名大按钮，重复入口没意义）。

## 5. 改这块代码时的注意

1. **不要新增第二套导航**（顶栏已有过一次就够）；新页面只要在 `nav-items.tsx` 里加一项。
2. `globals.css` 里绝大多数类名与几何（padding / 栅格）是**沿用老版**的，只换了颜色、圆角与阴影。
   改样式时优先动颜色变量，别顺手改尺寸 —— B/C 的布局都依赖这些数值。
3. **不要往按钮和卡片上加圆角**，也不要给卡片加辉光/阴影 —— 那会立刻破坏工业风。
4. 新增文案不要出现裸 `"`（`react/no-unescaped-entities` 是硬错误），中文引号用「」。
5. 暗底上新增颜色要自己验证对比度：浅黄 `#ffeb9a` 只用于点缀或深底上的文字；白字只放在 `--bg`/`--bg-deep` 上。
