# 前端 UI 重构说明（v4 视觉系统 · 浅色黑白工业风）

> 类型：**随开发演进**的文档（可直接改，不必等评审）。改的是外观与导航形态，**没有动任何业务逻辑与接口**。
> 沿革：v2 黑/亮黄/白 → v3 直角 + 黑白工业风（降黄调浅）→ **v4 把黑底与白字整体对调**（也就是现在这版）。

## 1. 两条不变的规矩 + v4 的对调

**规矩（务必守）**：
1. **一律直角** —— `--radius: 0`。按钮、卡片、输入框、标签、状态胶囊、品牌方块全是方块，
   不要加圆角或胶囊形。
2. **不要辉光与柔光** —— 层次只靠 1px 描边 + 极浅的叠底（`rgba(11,13,16,.04~.08)`）。
   给卡片加阴影/外发光会立刻破坏工业感。

**v4 的对调**：底色由近黑改成**纸白**，文字与主按钮由白改成**近黑**，
背景大图同步从「黑底光树」换成「**白底黑线稿**」（深色图在浅底上会直接打架）。

色板集中在 `src/app/globals.css` 的 `:root`：

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--bg` / `--bg-deep` | `#f4f5f3` / `#e9ebe8` | 纸白底 |
| `--ink` | `#0b0d10` | 近黑文字 / 黑块按钮 |
| `--muted` / `--faint` | `#5b6167` / `#8b9198` | 次级与三级文字 |
| `--accent` / `--accent-deep` | `#ffe9a3` / `#f7dd85` | **浅黄**，只作点缀（**不做文字色**，浅底上读不了） |
| `--line` / `--line-soft` / `--line-strong` | `rgba(11,13,16,.16/.09/.38)` | 描边三档 |

按钮语义：`.button`（主）= **黑底白字**，hover 变浅黄底黑字；`.button-secondary` = 透明 + 1px 深描边，
hover 反相成黑底白字。**白/黑才是主体，黄只在 hover、左侧竖条、「演示数据」角标三处出现。**

状态色走黑白体系：`status-completed` = 黑底白字实块；`status-in-progress` = 浅黄块深字；
`not-started` / `skipped` = 浅灰或虚线。错误提示（`.error-text`）保留去饱和的红，保证一眼认出。

## 2. 背景大图（v4 换成了线稿）

- 素材：`public/brand/key-visual.jpg`（首页：白底黑线树）、`public/brand/backdrop.jpg`（内页水印，**同一张图**），
  均 2560×1440。因为文字密集的内页撑不住一张实图，内页把它当 **16% 水印**用。
- 生产链：AI 文生图（pollinations.ai 免费接口，**宽度上限 1024**，出图带水印）→
  本地 Pillow 处理成**白底黑线**：灰度化 → 反相 → LUT 把「背景那一档」推到纯白、「线条那一档」压到近黑
  （顺手抹掉水印、地面阴影与 JPEG 噪点）→ LANCZOS 放大到 2560×1440 → 轻微锐化。
  `LUT` 的阈值带在 `[0.10, 0.22]`：带宽太宽背景会留灰，太窄线条会断。
- **属于 AI 生成素材，对比赛材料无版权争议**；换实拍或设计稿直接覆盖同名文件即可，代码不用动。
- 承载层 `.backdrop`（fixed + `pointer-events:none`）四层：`-photo` / `-glow` / `-grid` / `-veil`。
- 构图靠 `transform: translateX() scale()`（**不要用 `background-size` 百分比**，竖屏会露底色）。
  桌面把树推到右侧 20%，左半边留白给标题；**≤900px 时降到 20% 透明度当水印** ——
  窄屏正文占满宽度，实图一定会压到文字。
- 遮罩 `.backdrop-veil` 在浅色主题里是**纸白**而不是黑：左侧 97% 白（深色文字才压得住），
  右侧放开让线稿保持清晰。

## 3. 左侧自动呼出菜单（dock）

`src/components/app-shell.tsx`（客户端组件，挂在 `layout.tsx`，全站唯一）。
收起时只占左侧 16px（触屏 26px）窄栏；鼠标移入 / 键盘聚焦 / 点「固定」→ 滑出 248px 面板。

- 导航项集中在 `src/components/nav-items.tsx`，**顶栏与侧栏共用同一份**，不要再各写一遍。
- **当前项 = 黑实块 + 白字 + 3px 浅黄左竖条**。
- 面板里的链接**始终在 DOM 中**（靠 `transform` 移出视野，而不是 `display: none`），
  这样键盘 Tab 进来时 `:focus-within` 能把面板拉开，导航可达。
- 遮罩 `.dock-scrim` 默认 `pointer-events: none`：如果让它接事件，鼠标划过页面会一直停在
  `.dock:hover` 上，菜单关不掉。只有「已固定」状态才允许点击遮罩收起（触屏用）。
- 触屏没有 hover，**窄栏上的按钮是唯一入口**；`@media (hover: none)` 会把窄栏加宽到 26px。

## 4. 顶栏

`src/components/site-header.tsx`：品牌 + `匿名体验` 说明 + `编号 / 英文名` 面包屑 + 主行动按钮（黑底方块）。
导航本体已经在侧栏，顶栏刻意做薄，让背景线稿成为视觉主体。
测评页会隐藏顶栏的「开始测评」（页面自己有同名大按钮，重复入口没意义）。

## 5. 改这块代码时的注意

1. **不要新增第二套导航**；新页面只要在 `nav-items.tsx` 里加一项。
2. `globals.css` 里绝大多数类名与几何（padding / 栅格）是**沿用老版**的，只换了颜色、圆角与阴影。
   改样式时优先动颜色变量，别顺手改尺寸 —— B/C 的布局都依赖这些数值。
3. **不要加圆角、不要加辉光**（见 §1）。
4. 浅底上**不要用浅黄做文字色**（对比度不够）：黄只当色块底，字用 `--ink`。
5. 新增文案不要出现裸 `"`（`react/no-unescaped-entities` 是硬错误），中文引号用「」。
