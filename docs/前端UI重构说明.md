# 前端 UI 重构说明（v2 视觉系统）

> 类型：**随开发演进**的文档（可直接改，不必等评审）。改的是外观与导航形态，**没有动任何业务逻辑与接口**。
> 起因：比赛演示需要一个更"新潮"的第一印象 —— 大图打底 + 贴边自动呼出的功能菜单 + 黑/亮黄/白三色。

## 1. 三色与质感

色板集中在 `src/app/globals.css` 的 `:root`，改色只改那里：

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--bg` / `--bg-deep` | `#06070a` / `#000205` | 全站底色 |
| `--ink` | `#f4f5f2` | 正文白 |
| `--accent` | `#ffe14d` | 亮黄主色（按钮、选中态、强调线） |
| `--accent-ink` | `#0a0b0d` | 落在黄底上的字色 |
| `--line` / `--line-soft` | `rgba(255,255,255,.12)` / `.07` | 描边 |
| `--muted` / `--faint` | `#98a0aa` / `#6d757f` | 次级与三级文字 |

质感统一为「暗玻璃」：卡片与任务块用半透明白底 + `backdrop-filter: blur()` + 1px 描边，
黄只用在**可点/当前态/强调**上，避免大面积铺黄导致正文对比度不足。

## 2. 背景大图

- 素材：`public/brand/key-visual.jpg`（首页主视觉，黄金知识树 2560×1440）、
  `public/brand/backdrop.jpg`（内页底纹，金色轨道线）。
- 由 AI 文生图生成（pollinations.ai 免费接口，输出 1024×576），本地用 LANCZOS 放大到 2560×1440、
  抹掉服务方水印、补少量噪点抑制色带。**属于 AI 生成素材，对比赛材料无版权争议**；
  若后续要换成实拍或设计稿，直接覆盖同名文件即可，代码不用动。
- 承载层是 `.backdrop`（`position: fixed` + `pointer-events: none`），四层叠加：
  `-photo`（图）/ `-glow`（黄蓝双向辉光）/ `-grid`（76px 网格，径向遮罩）/ `-veil`（左右+上下压暗）。
- 首页与内页用**不同档位**：首页亮、位置偏右；内页压到 52% 且更靠右，保证正文区域足够暗。
- ⚠️ 主体位置用 `transform: translateX() scale()` 调，**不要用 `background-size` 百分比** ——
  竖屏下会露出底色。图片本身是放大来的，过大的 `scale` 会明显发虚。

## 3. 左侧自动呼出菜单（dock）

`src/components/app-shell.tsx`（客户端组件，挂在 `layout.tsx` 里，全站唯一）。
收起时只占左侧 16px（触屏 26px）的窄栏；鼠标移入 / 键盘聚焦 / 点"固定" → 滑出 248px 面板。

- 导航项集中在 `src/components/nav-items.tsx`，**顶栏与侧栏共用同一份**，不要再各写一遍。
- 面板里的链接**始终在 DOM 中**（靠 `transform` 移出视野，而不是 `display: none`），
  这样键盘 Tab 进来时 `:focus-within` 能把面板拉开，导航可达。
- 遮罩 `.dock-scrim` 默认 `pointer-events: none`：如果让它接事件，鼠标划过页面会一直停在
  `.dock:hover` 上，菜单关不掉。只有"已固定"状态才允许点击遮罩收起（触屏用）。
- 触屏没有 hover，**窄栏上的按钮是唯一入口**；`@media (hover: none)` 会把窄栏加宽到 26px。

## 4. 顶栏

`src/components/site-header.tsx`：品牌 + `匿名体验` 说明 + `编号 / 英文名` 面包屑 + 主行动按钮。
导航本体已经移到侧栏，顶栏刻意做薄，让背景大图成为视觉主体。
测评页会隐藏顶栏的「开始测评」（页面自己有同名大按钮，重复入口没意义）。

## 5. 改这块代码时的注意

1. **不要新增第二套导航**（顶栏已有过一次就够）；新页面只要在 `nav-items.tsx` 里加一项。
2. `globals.css` 里绝大多数类名与几何（padding/圆角/栅格）是**沿用老版**的，只换了颜色与质感。
   改样式时优先动颜色变量，别顺手改尺寸 —— B/C 的布局都依赖这些数值。
3. 新增文案不要出现裸 `"`（`react/no-unescaped-entities` 是硬错误），中文引号用「」。
4. 暗底上新增颜色要自己验证对比度：黄 `#ffe14d` 只配深字，白字只放在 `--bg`/`--bg-deep` 上。
