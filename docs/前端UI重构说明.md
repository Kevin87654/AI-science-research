# 前端 UI 重构说明（v5 视觉系统 · 浅色黑白工业风）

> 类型：**随开发演进**的文档（可直接改，不必等评审）。改的是外观与导航形态，**没有动任何业务逻辑与接口**。
> 沿革：v2 黑/亮黄/白 → v3 直角 + 黑白工业风（降黄调浅）→ v4 黑白对调成浅色 →
> **v5 左侧改常驻图标栏 + 放大排版 + 补 logo 占位**（也就是现在这版）。

## 1. 两条不变的铁律 + 字号基调

**铁律（务必守）**：
1. **一律直角** —— `--radius: 0`。按钮、卡片、输入框、标签、状态胶囊、logo 方块全是方块，
   不要加圆角或胶囊形。
2. **不要辉光与柔光** —— 层次只靠 1px 描边 + 极浅叠底（`rgba(11,13,16,.04~.09)`）。

**字号基调（v5 整体放大过一档，改之前先想清楚）**：正文 17px、`h1` 最大 92px、`h2` 最大 46px、
卡片标题 19px、主按钮 16.5px。改样式时优先动颜色变量，**别顺手改这些尺寸** ——
B/C 的布局都按这套字号调过。

色板集中在 `src/app/globals.css` 的 `:root`：

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--bg` / `--bg-deep` | `#f4f5f3` / `#e9ebe8` | 纸白底 |
| `--ink` | `#0b0d10` | 近黑文字 / 黑块按钮 / 图标栏选中标记 |
| `--muted` / `--faint` | `#555b61` / `#868c93` | 次级与三级文字 |
| `--accent` / `--accent-deep` | `#ffe9a3` / `#f7dd85` | **浅黄**，只作点缀（**不做文字色**，浅底上读不了） |
| `--line` / `--line-soft` / `--line-strong` | `rgba(11,13,16,.16/.09/.4)` | 描边三档 |
| `--rail` | `64px`（触屏/窄屏 56px、≤680px 52px） | 左侧常驻图标栏宽度 |
| `--dock-w` | `292px` | 展开面板宽度 |

按钮语义：`.button`（主）= **黑底白字**，hover 变浅黄底黑字；`.button-secondary` = 透明 + 1px 深描边，
hover 反相成黑底白字。**白/黑是主体，黄只在 hover、demo 角标、eyebrow 短杠、进行中状态块四处出现。**

## 2. 左侧常驻图标栏 + 展开面板（v5 重点）

`src/components/app-shell.tsx`（客户端组件，挂在 `layout.tsx`，全站唯一）。

- **收起时也看得见每个功能的图标**（64px 宽，图标 23px，浅灰 `#a9afb6`）——
  之前只留一条 16px 细线，功能完全不可发现，这是 v5 要修的问题。
- **选中项 = 浅灰块 + 左侧 3px 黑条**（对齐参考站那套标记），收起态与展开态一致。
- 三种展开方式：① 鼠标移入左栏（纯 CSS `:hover`）；② 键盘 Tab 进面板内的链接
  （`:focus-within`，所以**面板里的链接始终在 DOM 中、可聚焦**，不能靠 `display` 切换）；
  ③ 点左栏底部的按钮「固定」（触屏没有 hover，这是唯一入口）。
- **z-index 别漏**：面板是图标栏的后一个兄弟节点，默认会盖住图标栏 → 图标栏 `z-index: 2`、
  面板 `z-index: 1`，图标才始终露在外面；面板的左内边距用 `calc(var(--rail) + 14px)` 避开图标栏。
- 图标栏那一组链接是 `aria-hidden` + `tabIndex={-1}`：它们只是同一批目的地的视觉副本，
  让读屏重复念两遍是噪音；**可访问的那一份在展开面板里**（带 `aria-current`）。
- 遮罩 `.dock-scrim` 默认 `pointer-events: none`：如果让它接事件，鼠标划过页面会一直停在
  `.dock:hover` 上，菜单关不掉。只有「已固定」状态才允许点击遮罩收起（触屏用）。

## 3. Logo 占位

`src/components/logo.tsx` 导出 `LogoMark`（黑方块里画一棵"知识树"：主干 + 三条分支 + 节点圆点 + 地平线）
与 `LogoLockup`（方块 + 中文名 + `RESEARCH COPILOT` 英文副名）。

- 位置：**图标栏顶部**（42px 方块，兼作回首页入口）与**展开面板顶部**（42px + 文字组合）。
  顶栏**不再放 logo** —— 同一屏出现两个 logo 很别扭；顶栏改为显示「`编号 / 英文名` + 当前功能名」
  （首页显示标语「从认识科研，到迈出第一步」）。
- 意象与背景线稿一致（都是树），放一起不会有拼贴感。
- **真 logo 到位后只需替换 `logo.tsx` 里的 SVG**，调用处一处都不用改。

## 4. 背景大图

- 素材：`public/brand/key-visual.jpg`（首页：白底黑线树）、`public/brand/backdrop.jpg`（内页水印，**同一张图**），
  均 2560×1440。文字密集的内页撑不住一张实图，所以内页把它当 **16% 水印**用。
- 生产链：AI 文生图（pollinations.ai 免费接口，**宽度上限 1024**，出图带水印）→
  本地 Pillow 处理成**白底黑线**：灰度化 → 反相 → LUT 把「背景那一档」推到纯白、「线条那一档」压到近黑
  （顺手抹掉水印、地面阴影与 JPEG 噪点）→ LANCZOS 放大到 2560×1440 → 轻微锐化。
  LUT 阈值带在 `[0.10, 0.22]`：**带宽太宽背景会留灰，太窄线条会断**。
- **属于 AI 生成素材，对比赛材料无版权争议**；换实拍或设计稿直接覆盖同名文件即可，代码不用动。
- 承载层 `.backdrop`（fixed + `pointer-events:none`）四层：`-photo` / `-glow` / `-grid` / `-veil`。
- 构图靠 `transform: translateX() scale()`（**不要用 `background-size` 百分比**，竖屏会露底色）：
  桌面把树推到右侧 20%，左半边留白给标题；**≤900px 降到 20% 透明度当水印**（窄屏正文占满宽度，实图必压字）。
- `.page-shell` 有 `padding-left: var(--rail)`，顶栏用负 margin 抵消后铺满整宽 ——
  这样正文整体避开 fixed 图标栏，不会钻到图标下面。

## 5. 改这块代码时的注意

1. **不要新增第二套导航**；新页面只要在 `nav-items.tsx` 里加一项（图标栏与面板会同时生效）。
2. `globals.css` 里的类名与几何（padding / 栅格）沿用旧版，v5 只放大了字号与图标栏宽度。
3. **不要加圆角、不要加辉光**（见 §1）。
4. 浅底上**不要用浅黄做文字色**：黄只当色块底，字用 `--ink`。
5. 新增文案不要出现裸 `"`（`react/no-unescaped-entities` 是硬错误），中文引号用「」。
