# 大四毕设指导：方向与分工

> 版本：v0.6 ｜ 改动时间：2026-11-10 ｜ 用途：团队对齐方向与分工的内部文档，不提交给辅导员、不对学生发布。本文档仅供参考，对项目没有强制性约束，随开发随时改。

## 1. 这个项目是干什么的

把原来的「科研小助理」从"给大一新生做科研启蒙"，扩展出一个"**大四毕设指导**"入口。首页做一个欢迎页，选进"大一模块"还是"大四毕设模块"，两个模块隔离。交付给学院辅导员老师，不是毕设答辩项目。

辅导员要的是**覆盖毕设流程信息（时间线、开题、答辩要求）**。所以现在的重点是"**毕设时间轴**"：帮大四同学看清自己在毕设里走到哪一步、还差什么、什么时候该交什么。分两条线：

- **学校官方时间线**：选题、开题、中期、答辩这些固定节点，各节点的截止时间和材料要求；
- **个人/导师时间线**：导师分配的任务、时间周期、任务书完成度、每周进展。

近期先做**学生端**，让学生能可视化自己的毕设进度、收到提醒、按周记录进展、有和导师沟通的话术，最终能顺利毕业。

之前定的"导师搜索"和"兴趣匹配"两条线**保留，但优先级降低**。

| 功能 | 说明 |
|---|---|

## 9. 怎么协作、看进度

沿用比赛时的做法：

- 每个人做完就提交（PR），PR 里写清"改了什么、为什么"。文档也随 PR 一起改，不单独走文档评审。
- 开工前先看别人的 PR，掌握进度，避免重复或撞车。
- 部署在 Vercel：PR 合入后线上直接能看到效果，方便团队同步进度、体验、迭代，也方便给辅导员验收。现在 Vercel 主要就是团队内部 + 验收用；将来要公开发给学生，再部署到学校服务器（还没定）。
