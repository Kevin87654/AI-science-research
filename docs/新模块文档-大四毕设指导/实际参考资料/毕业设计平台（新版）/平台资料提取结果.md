## 0. 一句话结论（给产品决策用）

平台的进度模型是 **「轮次（批次）+ 环节工作台」**：全部 11 个环节各自有一段**时间窗**，时间窗由 **校级轮次时间 × 院系时间参数** 双重叠加决定，窗口一关按钮直接失效（提示"当前时间不在开始/结束时间内无法操作"）。
因此你们的学生端时间轴**不需要硬编码日期，而要镜像平台状态机**：每个环节 = 「窗口开始 / 窗口结束 / 我的状态 / 前置阻塞 / 审批链上谁在等我」。

## 1. 平台结构与时间窗机制（做字段前必须先理解）

### 1.1 入口与路径
- 统一门户：`https://ehall.szu.edu.cn/new/index.html` → 学号/工号登录 → 应用「**毕业论文（设计）**」
- 左侧菜单（学生只有 3 项）：`论文工作台`、`毕业论文相关规定`、`院系相关规定下载`
- 工作台内以 **页签（Tab）** 区分功能；**进入后必须先确认顶部"轮次（批次）"是否正确**（如"2027届毕业论文（设计）"）

### 1.2 环节链（两套，注意差别）

| 视角 | 环节顺序 |
|---|---|
| **学生端进度条（7 环节）** | 学生选题 → 任务书 → 开题报告 → 指导记录 → 中期检查 → 论文初稿 → 论文定稿 |
| **教师/管理端进度条（11 环节）** | 选题发布 → 学生选题 → 任务书 → 开题报告 → 指导记录 → 中期检查 → 论文初稿 → **论文评阅 → 论文答辩** → 论文定稿 → 成绩管理 |

> ⚠️ **两个必须在产品里标注的疑点**（建议找教务处/学院确认后再做死逻辑）：
> 1. 管理端链条里 **「论文答辩」排在「论文定稿」之前**，即系统里的"定稿"更像**答辩后的终版归档上传**，而不是"定稿=答辩前最终稿"。这直接影响时间轴最后两格的语义与提醒文案。
> 2. 学生端看不到"评阅/答辩/成绩"环节，但这两段（约 2–4 周）恰恰是学生最焦虑的**空窗期**，产品应补一个"我这边没事、等学校"的说明态。

### 1.3 时间窗机制（硬 deadline 的根源）

```
可操作 = 轮次已启动  AND  当前时间 ∈ 校级轮次时间窗  AND  当前时间 ∈ 院系时间窗
```

- 院系在【院系毕业论文设置】→「**时间参数设置**」里逐环节维护起止时间，**叠加**在校级轮次之上（见教秘手册 3.3）
- 时间参数是按环节成对的字段，实测列名包括：`课题申报开始/结束`、`学生选题开始/结束`、`任务书开始/结束`、`开题报告开始/结束`、`指导记录开始/结束`、`中期检查开始/结束`、`论文初稿开始/结束`（+ 评阅/答辩/定稿）
  → **这就是学生端时间轴最理想的字段母版**：一个环节 = 一对 `start_at / end_at`
- 另有参数：`指导记录最少完成篇数`（未达篇数**定稿不允许上传**）、`成绩占比`（指导/评阅/答辩）、`可申报课题数上限`、`单课题可带人数上限`、`单个修读方案可报名课题数量上限`（学生端实测=1）
- 窗口外的典型报错：`当前时间不在开始/结束时间内无法操作` → 官方给的处置口径：**联系对应院系教秘**（可延长/补设）

## 2. 毕设全流程时间线（学生视角，可直接落字段）

### 2.1 主表

> 列说明：**审批链** = 学生提交后要过几道关；**硬校验** = 不过就卡死后续环节的系统级依赖。

| # | 阶段 | 时间窗（由轮次×院系配置） | 学生在平台要做的操作（菜单路径 → 动作） | 要交的材料 | 审批链 | 硬 deadline / 逾期后果 |
|---|---|---|---|---|---|---|
| 1 | **选题报名**（学生选题） | 秋季学期初，约 2–4 周（示例 09-08～10-29） | 【论文工作台】→「学生选题」→「课题报名」页签：筛选（剩余名额/面向院系/面向专业/第一指导教师/合作指导教师）→ 看课题详情（导师、拟带人数、剩余名额、课题介绍、研究方向）→ 点「报名」→ 状态变"待教师确认"；未确认前可在「已报名课题」页签**取消报名** | 无附件（系统内选择，**不需要**交材料）；实际交的是"报名动作" | 学生报名 → **教师确认/拒绝**（可批量） | **窗口关闭即不能报名**；**已被教师确认的不可自行取消**，只能请教师发起解绑→专业负责人审核；单方案仅可报 1 个课题；被确认后不能再报其他课题 |
| 2 | **任务书确认** | 选题后、开题前（约 1–2 周） | 【论文工作台】→「任务书」→「任务书确认」页签：查看导师下达的任务书 → **点确认** | 系统内确认（无上传）；线下对应《2. 任务书》 | 教师下达 → **学生确认**（双学士学位课题：第二指导教师确认 → 学生确认） | 🔴 **任务书未经学生确认，系统会拦截后续"开题、定稿"等全部提交**。内容有异议不能自己改，只能先沟通、由**教师发起变更**（走"任务书变更"留痕） |
| 3 | **开题报告** | 与任务书窗口衔接（示例 09-01～10-28） | 【论文工作台】→「开题报告」页签：时间窗内**在线填写并提交**；未审核通过前可**撤回**修改；被退回后改完重新提交；通过后要改只能走「开题报告变更」 | 在线表单（对应线下《3. 开题报告》：选题意义及国内外发展状况 / 研究内容 / 研究方法、手段及步骤 / 参考文献） | **草稿 → 待教师审核 → 待专业负责人审核 → 已通过**（两级！） | 🔴 **开题审核通过是后续所有环节的必备条件**；窗口关闭后不能提交/不能撤回 |
| 4 | **指导记录**（周/次记录） | 贯穿整个做论文期（示例 09-02～10-30） | 【论文工作台】→「指导记录」页签：点「**新建**」逐篇新增记录（时间、内容）→ 等教师审核；列表可见"记录条数、审核状态" | 在线记录（对应线下《4. 进展情况记录表》：日期 + 讨论内容，含存在的问题和改进措施） | 草稿 → 待教师审核 → 已通过（教师端可"批量审核通过/批量退回"） | 🔴 **篇数不足直接不允许上传定稿**（示例要求 8 篇，篇数由院系参数定，**每年可能变**）。这是最容易被漏、后果最重的一项 |
| 5 | **中期检查** | 学期中（示例未给出；一般为次年 3–4 月） | 【论文工作台】→「中期检查」页签：查看导师下达的中期检查；页面同时显示"指导记录提交情况（已上传/未上传）" | 平台实测提示 **"中期检查无需确认"**（学生端一般无操作，仅查看） | 教师**下达**中期检查（学生不提交） | 无学生侧提交 deadline，但若学院要求交《中期检查表》，**当前 8 个模板里没有这张表**（见 §4 缺口） |
| 6 | **论文初稿** | 答辩前（示例 09-01～10-28） | 【论文工作台】→「论文初稿」→「上传论文」；页面列 `论文查重查看 / AIGC检测查看 / 格式检测查看 / 审核状态` | 论文正文附件（.doc/.docx/.pdf，具体格式以学院通知为准） | 草稿 → 待教师审核 → 已通过；**教师审核完毕后，才可提交查重、AIGC 检测、格式检测** | 🔴 **初稿环节完成 = 教师审核通过 + 查重通过**；检测不通过需改后重传（有次数限制，见 §5.4） |
| 7 | **论文评阅** | 初稿后（示例 09-01～10-31） | ❌ 学生无操作（教师/评阅教师端完成，教秘"盲抽分配"评阅教师） | （教师）《5. 评审表》中的"评阅人评审表" | 指导教师评阅 + 评阅教师评阅（各录意见/成绩） | 学生侧只有等待；评阅不通过影响答辩资格 |
| 8 | **论文答辩** | 次年 5 月前后（示例未给） | ❌ 学生无平台操作；线下按学院安排的场次参加答辩 | 现场：论文纸质稿 + PPT；线下《6. 答辩记录表》《7. 考核表》由答辩秘书/小组填写 | 答辩秘书录入成绩（**第一批 / 第二批（延期、二辩）**）、上传成绩考核表与答辩记录表 | 缺席/未过 → 进"第二批"（延期批，成绩按延期处理） |
| 9 | **论文定稿** | 最后一个窗口（示例 09-01～10-30） | 【论文工作台】→「论文定稿」→ 上传**终版**论文附件 | 终版论文附件（含封面、诚信声明、目录、正文、附录的完整稿） | 草稿 → 待教师审核 → 已通过；审核完毕后可提交查重/AIGC/格式检测 | 🔴 提交前系统做**前置校验**：任务书已确认 + 开题已通过 + 指导记录篇数达标 + 初稿检测已过。任一不满足 → 提交被拦截（提示"××未确认/未通过"） |
| 10 | **成绩** | 答辩后 | ❌ 学生无操作（可查询） | — | 教秘按专业审核 → **发布**（发布后不可改，改动需管理员放参数） | 总成绩 = 指导成绩×比例 + 评阅成绩×比例 + 答辩成绩×比例 |

### 2.2 学生视角的"硬闸门"清单（产品里要单独做成红色项）

| 闸门 | 谁卡住 | 卡住后的系统表现 | 解锁方式 | 预估耗时（给用户预期） |
|---|---|---|---|---|
| 报名后教师一直不确认 | 指导教师 | 状态停在"待教师确认" | 催教师；或取消报名改报 | 1–3 天（无 SLA，需催） |
| 任务书未确认 | **学生自己** | 开题、定稿提交被拦截 | 自己去点"确认" | 即时 |
| 开题未通过 | 教师 → 专业负责人（两级） | 后续全锁 | 改完重提，等两级审核 | 3–7 天/轮 |
| 指导记录 < N 篇 | **学生自己**（+教师审核） | **定稿不允许上传** | 补录 + 请教师审核通过 | 每篇 0.5–2 天 |
| 初稿查重/AIGC 未过 | 检测系统 | 初稿环节不完成 | 降重改稿 → 重传 → 重检（受次数限制） | 3–7 天 |
| 环节时间窗关闭 | 学校/学院参数 | 按钮消失或报"不在操作时间内" | **只能联系院系教秘延长** | 不确定，越早越好 |
| 已被确认却想换导师 | 教师 + 专业负责人 | 无法自行取消 | 教师发起解绑申请 → 专业负责人审核 | 数天；⚠️ **解绑通过后该生"中期检查"等过程数据会被同步删除**（务必警示） |

| 成绩 | 查询 | 录指导成绩；被安排时录评阅成绩 | — | 分项成绩录入状态 |

### 3.3 导师端到底能看到学生的什么？

从教师手册截图实测，导师在**每个环节页签下看到的是"学生状态矩阵"**，字段为：

- **身份列**：学号、姓名、年级、院系、专业、论文题目、方案修读类型、培养方案名称、是否学士双学位、第一/第二/合作指导教师
- **状态列随环节变化**：
  - 指导记录：`记录条数`、`审核状态`（草稿/待审核/已通过）、`课题指导类型`
  - 初稿/定稿：`论文查重查看`、`AIGC检测查看`、`格式检测查看`、`审核状态`
  - 评阅：`是否提交`、`成绩审核状态`
- **能看到的内容本体**：任务书、开题报告正文、指导记录内容、初稿/定稿**附件与检测结果**
- **看不到的**：其他导师名下学生、其他院系数据；评阅教师由教秘"盲抽分配"且**不会分到自己带的学生**（盲审机制）

> 对产品的含义：学生端做「导师视角镜像」很有价值——直接告诉学生"老师那边现在看到你是**草稿**，还没提交"，能显著减少"我交了老师没看到"的沟通成本。

## 5. 撰写规范 + 查重要点

### 5.1 论文基本结构（撰写规范 PDF 原文）

1. **前置部分**：封面、诚信声明、论文目录
2. **主体部分**：中文摘要 → 中文关键词 → 前言（引言/序言）→ 正文 → 注释与参考文献 → 致谢 → 英文摘要和英文关键词
3. **附录部分（非必需）**：重要的原始数据、图纸等

**装订顺序**：封面 → 诚信声明 → 目录 → 主体部分 → 附录

### 5.2 内容硬指标（可直接做成校验规则）

| 项目 | 要求 | 可自动化 |
|---|---|---|
| 中文摘要 | **不少于 200 字** | ✅ 字数统计 |
| 关键词 | **3–4 个**，每词**≤6 字**，**分号**分隔 | ✅ 正则+计数 |
| 正文字数 | **不少于 12000 字** | ✅ 字数统计 |
| 参考文献 | **≥10 篇，其中外文 ≥2 篇** | ✅ 计数（语言判断半自动） |
| 艺术类/建筑学等毕业设计 | **≥6 张设计图 + ≥2000 字设计说明书**，参考文献 ≥8 篇（外文 ≥2） | ⚠️ 需人工/学院确认 |
| 外文文献翻译 | **3000 汉字左右**，与选题领域相关，**最好近三年发表** | ✅ 字数统计 |

### 5.4 参考文献格式（三类 + 分科差异）

- **期刊**：序号、作者、文献题目、期刊名、年份、卷号、期号
- **著作**：序号、作者、书名、出版单位、出版年月、页码
- **网络资源**：序号、作者、文献题目、网址（若网上资料已正式出版/发表，**最好按期刊/著作标注**）
- **分科差异**：文科参照《深圳大学学报（社科版）》，理工科参照《深圳大学学报（理工版）》；学院可另订细则报学校备案
- 正文中直接引用他人结论、观点、数据、图表，**均需标注**

### 5.5 查重 / AIGC / 格式检测（⚠️ 关键：材料里没有阈值）

平台确实内置三项检测，但**这批文档里没有任何重复率阈值、AIGC 率阈值、检测次数规则**：

| 事实（有据） | 出处 |
|---|---|
| 三项检测 = **论文查重、AIGC 检测、格式检测** | 教师手册七/十；学生端初稿页列 `论文查重查看/AIGC检测查看/格式检测查看` |
| **教师审核完初稿/定稿后，才能提交**这三项检测 | 教师手册 §7、§10 |
| 学生端只能"查看"结果，不能自己发起检测 | 学生端截图（初稿页仅有"上传论文"） |
| 检测状态呈"论文未通过/通过" | 教师端截图 |
| 教秘端可**逐生增加查重次数/AIGC 次数**、**更新进度获取相似度/AI率**、失败可删除重检、"论文相关内容、附件退回"重提 | 教秘手册 §7 |
| "不在校内论文系统做论文的学生"走 **外部论文查重管理** 上报 | 教秘手册 §7 |
| 有 **校内抽检** 菜单 | 教务管理员端菜单截图 |

> 🔴 **结论**：阈值（如"重复率 ≤X%"、"AIGC ≤Y%"）与检测次数上限**不在这 8 个文件里**。它们应在《深圳大学本科生毕业论文（设计）实施办法（修订）》——任务书须知第 1 条点名引用该文件，但**平台「毕业论文相关规定」列表里只挂了这 7 个文件，没有《实施办法》**。
> 产品动作：① 检测相关文案不要写死阈值；② 把"去看《实施办法》原文"做成待补充资料项；③ 找教务处要这份文件。

## 6. 学生端工具：最该先做的 4 条（按 ROI 排序）

### ① 时间轴 = 平台状态机的镜像（不要手填日期）
**做什么**：一个纵向时间轴，每环节一张卡，卡片 4 个字段全部来自平台语义：

| 字段 | 类型 | 枚举/说明 |
|---|---|---|
| `stage` | enum | 选题 / 任务书 / 开题 / 指导记录 / 中期检查 / 初稿 / 评阅 / 答辩 / 定稿 / 成绩 |
| `window_start / window_end` | datetime | 精确到 `00:00:00`（平台就是秒级） |
| `my_status` | enum | 未开放 / 可操作 / 待对方处理 / 待我处理 / 已通过 / 被退回 / 已过期 |
| `blocked_by` | ref[] | 指向前置环节（见 ②） |

**为什么先做**：学生的真实痛点不是"不知道流程"，而是**"我现在该干什么 / 还来不来得及"**。时间窗是平台唯一的硬约束，做对了这一屏就有 80% 价值。
**关键文案**：过期态必须给出**唯一正确出口**——"窗口已关闭，请立即联系【院系教秘】延长/补设"（这是四本手册共同给的官方口径，学生手册 §2 注意、教秘手册 FAQ 都是这句）。

### ② 阻塞链可视化（谁能解、要几天）
**做什么**：把 §2.2 的 7 个闸门画成依赖图，学生点"我卡住了"→ 直接告诉他：
- 卡在谁手里（我 / 导师 / 专业负责人 / 教秘 / 检测系统）
- 官方解锁动作是什么（例：任务书→"你自己点确认"；解绑→"教师发起申请 → 专业负责人审核"）
- 预计耗时（示例值，可标注"通常 3–7 天"）

**为什么值**：平台给的报错极其含糊（"××未确认/未通过"），学生第一反应是找老师，而很多情况**是他自己漏点了"确认"**，或漏了指导记录篇数。这一屏能砍掉大量无效沟通。

### ③ 指导记录计数器 + 催办（最高频、最易漏、后果最重）
**做什么**：
- 进度环：`已完成 X / 要求 N 篇`（N 从院系参数读，**示例 8**，别写死）
- 状态分解：`草稿 a 篇 / 待审核 b 篇 / 已通过 c 篇`（只有"已通过"才算数！）
- 时间提醒：`距上次指导记录已 D 天`；建议 `N 篇 ÷ 剩余周数 = 每周 X 篇`
- 红线提示：**"篇数不足，定稿会被系统直接拒绝上传"**

**为什么值**：这是唯一一个"学生能完全自主控制、但极易在 11 月/12 月被忘掉、且直接卡死毕业"的项。产品价值密度最高。

### ④ 材料清单 + 模板下载 + 自检清单
**做什么**：
- 把 8 个模板按环节挂到时间轴上（哪个环节该填哪张表，直接给下载）
- 双学位/辅修学生自动切换到"辅修版"模板（差别只在多一个"辅修学士学位专业"字段）
- 内置 §5.2 的**硬指标自检**：字数 ≥12000、摘要 ≥200、关键词 3–4 个每词 ≤6 字、参考文献 ≥10 篇（外文 ≥2）、图表编号 `图1/表1`、标题层次五选一不混用
- 明确标注"平台不提供 LaTeX 模板" + 给格式要求速查表

**附加（第 5 条，可后做）**：**双学位/辅修视角切换器** —— 平台有"主修/辅修学士学位"两套修读类型，学生手册 FAQ 里"报名提示专业不相同"的主要成因就是**方向/视角选错**，且数据上要切到辅修视角才看得到辅修课题。若目标用户含双学位学生，这个小功能能消灭一个高频报错。
