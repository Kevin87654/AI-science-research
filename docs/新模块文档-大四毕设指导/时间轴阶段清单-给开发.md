# 毕设时间轴 · 阶段内容清单（给开发）

> 用途：确定「大四毕设时间轴」的**阶段划分、每阶段要做什么、产出什么材料**，保证各阶段口径一致。
> 说明：只保留"阶段 + 内容 + 材料"，不含平台接口/状态机/硬闸门（现阶段拿不到学校接口，先不做）。
> 来源：深大毕业设计平台（新版）官方文档提取，2026-11-10。

## 全流程阶段（学生视角，共 10 个，按顺序）

| # | 阶段 | 这个阶段在做什么 | 产出 / 材料 |
|---|---|---|---|
| 1 | 选题 / 选导师 | 找导师聊方向、定题；在平台报名课题，等教师确认 | 无附件（只是"报名"动作） |
| 2 | 任务书 | 导师下达任务书（题目、基本内容与要求、进度安排、参考文献、选题来源）；学生查看并确认 | 《任务书》 |
| 3 | 开题报告 | 学生写：选题意义及国内外发展状况、研究内容、研究方法/手段/步骤、参考文献，提交审核 | 《开题报告》 |
| 4 | 指导记录 | 按次记录与导师的讨论（日期 + 讨论内容，含存在的问题和改进措施），贯穿整个做论文期 | 《进展情况记录表》 |
| 5 | 中期检查 | 导师下达；学生基本无操作（平台上"中期检查无需确认"） | 无（8 个模板里没有中期检查表） |
| 6 | 论文初稿 | 上传论文正文；教师审核后做查重 / AIGC / 格式检测 | 论文正文（.doc/.docx/.pdf） |
| 7 | 论文评阅 | 学生等待；指导教师 + 盲审评阅教师打分 | 《评审表》（学生不填） |
| 8 | 论文答辩 | 线下答辩（论文纸质稿 + PPT）；答辩秘书录成绩 | 《答辩记录表》《考核表》 |
| 9 | 论文定稿 | 上传终版（封面 + 诚信声明 + 目录 + 正文 + 附录完整稿） | 终版论文 |
| 10 | 成绩 | 学生查询成绩 | — |

## 每阶段大致时间（推演，必须标注"以学院通知为准"）

- 大三下～暑假：找导师、定方向（线下，不占平台环节）
- 大四上 9–10 月：选题 → 任务书 → 开题报告
- 大四上 10–12 月：做实验 / 写代码 / 跑数据，攒指导记录
- 大四下 3–4 月：中期检查 → 论文初稿
- 大四下 4–5 月：查重降重 → 评阅 → 答辩
- 大四下 5–6 月：论文定稿 → 成绩

## 8 个过程材料模板（对应上面阶段）

封面、任务书、开题报告、进展情况记录表（=指导记录）、评审表、答辩记录表、考核表、诚信声明

## 开发时注意（别写死的东西）

1. **各环节具体起止日期**：官方文档里只有演示数据（如"2026 届管理学院"），不能当真；时间轴上的日期做成"可配置 + 标注以学院通知为准"。
2. **"答辩"排在"定稿"之前**（系统里的"定稿"= 答辩后的终版归档）——时间轴最后几格的顺序按"…初稿 → 评阅 → 答辩 → 定稿 → 成绩"来，文案别写成"定稿 → 答辩"。
3. **查重 / AIGC 阈值、检测次数**：官方文档里没有，别在文案里写死具体数字。
4. **双学位 / 辅修**：过程材料有"辅修版"，只多一个"辅修学士学位专业"字段（可后做）。
