`src/features/graduation/school-milestones.ts`，学生不能增删。

## 4. 接数据库时改哪几处

仓库里**已经有**数据访问适配层（`src/server/repositories/`），
但**只覆盖两张表**：`sessions`（匿名会话的令牌摘要）与 `task_progress`（学习路线任务进度）。
**没有**账号表、导师-学生关系表、毕设节点表 —— 这三样需要新增。

### 4.1 建议的表结构

```sql
-- 账号：学号/工号即 id；密码只存哈希
create table public.accounts (
  id            text primary key,                       -- 学号 / 工号
  role          text not null check (role in ('student', 'mentor')),
  name          text not null,
  affiliation   text not null default '',
  detail        text not null default '',
  password_hash text not null,
  created_at    timestamptz not null default now()
);

-- 导师-学生关系：主键里带 mentor_id，查询必须带归属
create table public.mentor_students (
  mentor_id  text not null references public.accounts (id) on delete cascade,
  student_id text not null references public.accounts (id) on delete cascade,
  created_at timestamptz not null default now(),
  primary key (mentor_id, student_id)
);

-- 学生自建节点
create table public.graduation_nodes (
  id         uuid primary key default gen_random_uuid(),
  student_id text not null references public.accounts (id) on delete cascade,
  node_date  date not null,
  title      text not null check (length(title) between 1 and 40),
  note       text check (note is null or length(note) <= 200),
  created_at timestamptz not null default now()
);
create index graduation_nodes_student_date_idx on public.graduation_nodes (student_id, node_date);

-- 已有 sessions 表加一列，把匿名会话与账号绑起来
alter table public.sessions add column if not exists account_id text references public.accounts (id);
```

三张新表同样要 `enable row level security` 且**不建 policy**（理由见《数据库交接说明》§5：
API Key 带 `bypassrls`，RLS 挡不住我们，归属过滤必须写在 Repository 里）。

### 本机依赖布局的一个坑（2026-11-10 记录）

这台机器上 Node 24.21 + pnpm 11.19 的默认 `isolated` 布局会生成 junction，
Node 的 `require` 解析不进去（`require("@swc/helpers/...")` 直接 MODULE_NOT_FOUND），
表现为 `pnpm dev` / `next build` 报 `Could not find the Next.js package`。

本次验证是把布局换成 hoisted 才跑起来的：

```bash
pnpm install --frozen-lockfile --ignore-scripts --node-linker=hoisted
```

⚠️ pnpm 会在每次跑脚本前按配置校正布局，所以**没有把 `node-linker` 写进配置时，
下一条 pnpm 命令可能又切回 isolated**；只是看页面的话，装好后直接
`node node_modules/next/dist/bin/next dev` 也能起。部署端（Vercel / Linux）用默认布局即可，
不受此影响。
