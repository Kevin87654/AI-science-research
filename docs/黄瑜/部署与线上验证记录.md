## 2. 环境变量

线上**只需要两个**，且**名字必须带 `SERVER_` 前缀**：

| 变量名 | 必需 | 说明 |
| --- | --- | --- |
| `SERVER_CLOUDBASE_PG_REST_BASE_URL` | ✅ | 网关地址 |
| `SERVER_CLOUDBASE_PG_API_KEY` | ✅ | 管理员级密钥，**建议开启 Vercel 的 "hide value after saving"** |
| `SERVER_CODEBUDDY_API_KEY` | 暂不需要 | `.env.example` 里的占位。当前 `src/` 中**没有任何代码引用它**，AI 层未接。真正接 AI 时再补，补完只需重新部署一次 |

- Environment 至少勾 **Production + Preview**。
- 🚨 **变量名写错不会报错。** 应用找不到这两个变量会**静默退回内存实现**——页面照常打开，但数据每个请求一份、重启即清空。唯一露馅的地方是 `/api/ping` 会显示 `"database": "not_connected"`。**部署完必须用 §4 的第 1 步验证一次。**
- ⚠️ 粘贴值时留意别带多余的空格或换行（API Key 是 932 字符的长串，从别处复制容易多带换行）。

## 5. 中国大陆可达性

这是**唯一还没验完**的一项，也是风险最高的一项。

### 已确认的事实

| 项 | 结果 |
| --- | --- |
| `vercel.com`（控制台域名）大陆直连 | 【已实测】200，**0.20 秒**，DNS 解析正常，**未被污染** |
| `vercel.com` 经代理访问 | 【已实测】200，2.02 秒（比直连慢 10 倍） |
| `*.vercel.app`（部署域名）大陆可达性 | **【待验证】只能真机实测** |

### 已知风险

**`*.vercel.app` 在中国大陆被 DNS 污染。** Vercel 官方知识库承认：在中国大陆没有服务器或 CDN 节点，**不保证大陆的可用性与性能**【已核实】。

⚠️ **注意区分两件事**：被污染的是**部署出来的网站域名**（`*.vercel.app`），**不是控制台域名**（`vercel.com`）。前者打不开、后者能直连，两者经常被混为一谈。

### 验证方法（只能由真人在真机执行）

**关闭 Wi-Fi、使用手机移动数据**访问 `https://ai-science-research.vercel.app`。
建议中国移动、中国电信、中国联通各试一次——三家运营商的解析与线路不同，结果可能不一致。

### 如果打不开，按代价从低到高

1. **绑一个自己的域名**，把 CNAME 指向 `cname-china.vercel-dns.com`（注意比默认值多一个 `china`——这是 Vercel 面向中国大陆的专用解析入口）。社区实测可改善，但 Vercel 官方仍不保证稳定。
2. 换大陆可访问的托管平台（需要改部署方式，且**在没有自己域名时未必更好**——见下）。

⚠️ **换平台不是万能解**：在没有自己域名的情况下，境外平台的默认域名**普遍**存在大陆可达性问题，换一家未必更好。已核实的一例：腾讯云 EdgeOne Makers 的免费版默认域名在中国大陆网络下**只能用系统生成的预览链接访问、有效期 3 小时**，想稳定访问必须绑定**已备案**的域名。

### 赛事侧的口径（降低这项的优先级）

《赛事群答疑》里老师原话：**"有链接就可以了，可以用 Vercel，其他的也可以"**，且 **"初赛提交 demo 即可，不用部署到正式环境"**。→ 链接不是初赛的硬门槛。

## 7. 复现方式

全部是标准 HTTP 调用与仓库内脚本，不依赖任何专有 SDK。

```bash
# 线上自检（不需要密钥）
curl -s https://ai-science-research.vercel.app/api/ping

# 线上隔离验收（需要本地 .env.local，仅用于跑完后的清理）
node --env-file=.env.local scripts/verify/identity-isolation.mjs https://ai-science-research.vercel.app
```

本地对照：

```bash
node_modules/.bin/next build && node_modules/.bin/next start -p 3100
node --env-file=.env.local scripts/verify/identity-isolation.mjs http://127.0.0.1:3100
```
