## 三、选题

### Q5 题目怎么选？同时满足多个选题可以吗？

**老师**：是 9 选 1。9 个题目任选其一，多出的可以作为额外功能。

> 注：确认"9 选 1"的那次提问未包含在本摘录中；"多出的可以作为额外功能"是答复"同时满足多个选题可以吗"。

## 四、第三方模型 API 与运行时 AI

### Q6 最终 Web 应用在运行时，是否允许调用团队自有的第三方模型 API？

**同学**（方向一"多模态教学智能体"）：我们想确认一下第三方模型 API 的使用规则。我们会按要求使用 LearnBuddy 进行项目开发，并提交真实使用记录。最终 Web 应用在运行时，是否允许调用团队自有的第三方模型 API，例如 DeepSeek，来完成教学问答和图片理解？

**老师**：本次赛事以腾讯 LearnBuddy 平台为载体，**最终效果呈现时最好不要包含第三方 AI**。

### Q7 平台有没有开放给网页的 API？

**老师**：**平台本身没有开放给网页的 API。**

### Q8 那项目的图文解析该如何完成？

**同学**：LearnBuddy 没有可调用的 API，也不允许调用第三方 API，我们的项目图文解析该如何完成？

> ⚠️ 本问题**当时没有得到直接答复**。

### Q9 初赛的作品形态是什么？

**老师**：**初赛的作品形态是提交 demo 即可，不用部署到正式环境。** 在 LearnBuddy 上面搭建的智能体可以有多种形式，可以是 web demo，也可以是专家智能体，这些智能体做完之后是可以跟它进行交互体验使用的。

## 附 A：赛事手册中的作品要求（原文）

作品要求：作品须部署至浏览器环境，提供可直接访问的在线链接；须提交完整的源代码仓库（GitHub/Gitee 链接）；需提交 LearnBuddy 历史对话记录作为评审参考。
